R programs for “Adaptive spectral analysis for nonstationary functional time series”

To use these functions, users should download and unzip Rprogs_FPCA_AFSE.zip to a suitable directory. The file is available at https://github.com/zhangshibin-repository/BayesInfe_FunctionSpec. It contains the main R scripts
algorithm1.R, algorithm2.R, and algorithm3.R, together with several supporting scripts. 


To implement the algorithms, please see "guidance_Rprogs_AdaptiveSpectral_FTS.pdf" for a guide of R programs for “Adaptive spectral analysis for nonstationary functional time series”.
